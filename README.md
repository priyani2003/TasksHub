# TasksHub – Mobile Application Development

## Introduction
TasksHub is a mobile application developed using React Native and Expo as part of Tutorial 07.

## Features
- Add new tasks with task names and descriptions.
- Store tasks permanently using AsyncStorage.
- Display saved tasks on the Dashboard.
- Send local notifications when a task is saved.
- View and update student profile details.
- Select a profile picture from the device gallery.
- Clear saved task and profile data.

## Technologies Used
- React Native
- Expo
- TypeScript
- Expo Router
- AsyncStorage
- Expo Notifications
- Expo Image Picker

## Development Environment
The application was developed using Visual Studio Code.

## Project Structure
- `app/` – Application screens and navigation.
- `assets/images/` – Background and banner images.

## Conclusion
This application demonstrates persistent local storage, file-based navigation, local notifications, and image selection in a React Native application.
